# Ola Ride Analytics Project

## Overview

This project analyzes Ola ride booking data to uncover insights related to customer behavior, ride cancellations, revenue trends, and operational performance.

The analysis was performed using SQL, Excel, and Power BI.

---

## Tools Used

* SQL
* Excel
* Power BI

---

## Key Insights

* Identified high revenue-generating customers and routes
* Analyzed ride cancellation patterns
* Compared payment method usage and revenue contribution
* Evaluated customer and driver ratings
* Investigated incomplete rides and operational issues
